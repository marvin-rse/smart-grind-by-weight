# v1.5.9-beta.2 – V2 (untested)

Application image for the Waveshare 1.64" **V2** (SH8601) board, built by the
[v1.5.9-beta.2 release](https://github.com/marvin-rse/smart-grind-by-weight/releases/tag/v1.5.9-beta.2).

**Changes compared to v1.5.9:**
- Delete a single grind from the web interface history (also removed from lifetime statistics).
- No green flash on the display at power-on.

**Status:** Built and unit-tested, **not yet tested on hardware**.

## Install

Grinder web page → *System & updates → Manual firmware file* →
`smart-grind-by-weight-v1.5.9-beta.2-waveshare-164-v2.bin` → *Upload firmware*,
or select v1.5.9-beta.2 (pre-release) in the [web flasher](https://marvin-rse.github.io/smart-grind-by-weight/).

## Revert

Upload the stock image from [`../v1.5.9-v2/`](../v1.5.9-v2/) the same way.
