# v1.6.2 – V2

Application image for the Waveshare 1.64" **V2** (SH8601) board, built by the
[v1.6.2 release](https://github.com/marvin-rse/smart-grind-by-weight/releases/tag/v1.6.2)
(build #8).

**Changes compared to v1.6.1:**
- No stutter when swiping between doses: the selected profile is stored after
  the animation instead of during it.

## Install

Grinder web page → *System & updates → Manual firmware file* →
`smart-grind-by-weight-v1.6.2-waveshare-164-v2.bin` → *Upload firmware*,
or select v1.6.2 in the [web flasher](https://marvin-rse.github.io/smart-grind-by-weight/).

## Revert

Upload the image from [`../v1.6.1-v2/`](../v1.6.1-v2/) the same way.
