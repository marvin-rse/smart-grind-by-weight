# v1.6.3 – V2

Application image for the Waveshare 1.64" **V2** (SH8601) board, built by the
[v1.6.3 release](https://github.com/marvin-rse/smart-grind-by-weight/releases/tag/v1.6.3).
What it changes compared with the upstream firmware is listed in the
[README](../../README.md#whats-different-in-this-fork).

## Install

Grinder web page → *System & updates → Manual firmware file* →
`smart-grind-by-weight-v1.6.3-waveshare-164-v2.bin` → *Upload firmware*,
or select v1.6.3 in the [web flasher](https://marvin-rse.github.io/smart-grind-by-weight/).
Keep the page open until it reports the new build.

Older versions, including the upstream v1.5.9, are available under
[Releases](https://github.com/marvin-rse/smart-grind-by-weight/releases).
