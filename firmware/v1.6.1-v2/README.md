# v1.6.1 – V2

Application image for the Waveshare 1.64" **V2** (SH8601) board, built by the
[v1.6.1 release](https://github.com/marvin-rse/smart-grind-by-weight/releases/tag/v1.6.1)
(build #7).

**Changes compared to v1.6.0:**
- Smoother display, especially when swiping between doses.
- Firmware updates are offered from this fork instead of the upstream project.
- The grind history keeps the latest 50 sessions.

## Install

Grinder web page → *System & updates → Manual firmware file* →
`smart-grind-by-weight-v1.6.1-waveshare-164-v2.bin` → *Upload firmware*,
or select v1.6.1 in the [web flasher](https://marvin-rse.github.io/smart-grind-by-weight/).

## Revert

Upload the image from [`../v1.6.0-v2/`](../v1.6.0-v2/) the same way.
